## Two Modes

| Mode | Who starts the agent | Channel |
|---|---|---|
| **Listen** | The person, in their own terminal | Agent → `archa mcp` (stdio). Works with any MCP client |
| **Launch** | ArchaDev ("Send to agent", `archa run`) | Core spawns the CLI headless + reads its stream; agent → `archa mcp --run <id>` |

Ported from Gungnir's `remediate/` package (Go → TypeScript), which runs this flow with the same four agents. Code: `packages/agents/` (`@archa/agents`, **built**). **Today:** `agent-adapters.ts`, `agents.ts` (`ChatRunner`, behind its own `ChatHost` interface), `accounts.ts`, `keyring.ts`, `personas.ts`, `skills.ts`, `memory.ts`, `mcp-servers.ts`, `chat-store.ts`; wired by `@archa/host` → [CODE_MAP/07](./CODE_MAP/07-agents-mcp.md). Not built yet: worktrees, the review loop, Hermes.
