# Rendering — 04: Background Removal

**Phase:** MVP. Code: `apps/desktop/src/main/models.ts`, `main/ml-host.ts`, `renderer/lib/removeBackground.ts`. Entry points: canvas right-click **Remove background**, Design panel → Image → **Remove background**.

---

## What It Does

Cuts the subject out of an image node, on this computer. The photo never leaves the machine; only the model weights are downloaded, once.

| Step | Where | Detail |
|---|---|---|
| 1. Input | Renderer | Decode `src`, stretch to 1024 × 1024, pack RGB bytes (3 MB) |
| 2. Model | Main | `ml:segment` IPC (zod-checked size). Ensures the model file, then asks the ML host |
| 3. Inference | ML host (`utilityProcess`) | ONNX Runtime (native, CPU), ImageNet normalisation, sigmoid → 1024² mask (0-255) |
| 4. Compose | Renderer | Mask upscaled (bilinear) over the full-size pixels with `destination-in` → PNG data URL |
| 5. Apply | Renderer → core | One `update { src }` op labelled "Remove background" — undo restores the photo |

A mask with almost no foreground (mean < 2/255) is refused with "No clear subject found" instead of producing an empty image. If the node's `src` changed while the model ran, nothing is applied.

---

## Model

| Choice | Value | Why |
|---|---|---|
| Model | BiRefNet lite, ONNX export by onnx-community | MIT licence; clean hair edges (ISNet, Apache-2.0, left a halo in tests) |
| File | `ARCHA_HOME/cache/models/birefnet-lite.onnx` (fp32, 224 MB) | Derivable cache ([CACHE](../CACHE.md)): delete → downloaded again |
| Download | `net.fetch` in main, `.part` file renamed when complete, `model:progress` events | Shown on the canvas and in the Image section |
| Runtime | `onnxruntime-node`, CPU, `enableCpuMemArena: false`, `enableMemPattern: false` | ~0.4-0.7 GB instead of ~6 GB; ~11 s load + ~15-20 s per image on a laptop CPU |

Rejected: `onnxruntime-web` (WASM runs out of its 4 GB heap at 1024²), DirectML (crashed the RTX laptop GPU in tests), RMBG (non-commercial licence), imgly ISNet export (AGPL).

---

## Process Rules

- The ML host is separate from main and the core host: a native crash or the model's memory never takes documents down.
- Started on first use, closed after 3 minutes idle and on app quit. A request in flight when it exits fails with a retry hint.
- One job at a time (`bgJob` in the store); the menu item and button are disabled while one runs.
- Packaging: `onnxruntime-node/bin/**` is `asarUnpack`ed; darwin, linux and win32/arm64 binaries are excluded from the installer.

Not built: background removal for agents (`execute`), batch removal, refine-edge brush.
