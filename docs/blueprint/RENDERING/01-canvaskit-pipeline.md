# Rendering — 01: CanvasKit Pipeline

← [RENDERING.md](../RENDERING.md) | [Blueprint INDEX](../INDEX.md) | [02 — Layers →](./02-layers-hit-testing.md)

**Phase:** 1 (headless), 2 (app). Code: `packages/render/src/`.

> **Current state (MVP):** `packages/render` ships a **Canvas2D backend** (`draw.ts`, `scene.ts`) with a per-frame bitmap cache (`cache.ts`). The `drawNode(ctx, doc, node)` contract below is kept so CanvasKit can replace it without touching callers. Skia-in-WASM is confirmed as the target by [REFERENCE.md](../REFERENCE.md).

```

├── index.ts            createRenderer, exportImage, exportSvg, exportPdf
```

## Draw Order per Node

```
save → transform (x, y, rotation) → opacity / blend layer (only if needed)
  → clip (frame.clip)
  → fills (in order) → children (frames, groups) → strokes (inside/center/outside) → effects
restore
```

- Effects that need a layer (blur, layer blur, opacity < 1 with children) use `saveLayer` — and mark the node "expensive" → L4 bitmap cache.
- Images: decoded once per mip level from the asset store; never decode at full resolution beyond the zoom need.

**Canvas2D backend today:** `polygon` and `path` draw through `polygonPoints` / `viewBoxMatrix` (`packages/core/src/shapes.ts`, shared with SVG export). `image` decodes once per `src` (`packages/render/src/images.ts`); drawing a not-yet-decoded image paints a placeholder and the canvas repaints on load, one-shot renders (`renderNodePng`) wait for decode. `embed` draws a placeholder card (what exports and agent screenshots see); the app lays a sandboxed `<webview>` over it (`canvas/EmbedLayer.tsx`, partition `persist:archa-embed`, guarded in main by `will-attach-webview`). The live page sits **above** the canvas, so nodes drawn over an embed are hidden behind it. The node is the page itself: the link is asked once (new pages start empty, Phone 390 × 844), the card and toolbar never show it, and the page's scrollbars are hidden by injected CSS. A wheel over the selected embed is forwarded with `sendInputEvent`; double-click enters it. The toolbar snaps to Phone / Tablet / Desktop and saves JPG screenshots through `main/embed-shot.ts` (`wide` = CDP device override 1440 × 900, `object` = as shown).

## Text

| Rule | Detail |
|---|---|
| Shaping | CanvasKit `ParagraphBuilder`; results cached in L2 |
| Fonts | Loaded from asset store / system / Google Fonts download into `~/.archadev/cache/fonts/`. **Built:** 16 OFL families ship with the app (`scripts/gen-fonts.mjs` → `renderer/lib/bundled-fonts.ts` + `protocol/src/fonts.ts`, registered under their real names); `render/src/fonts.ts` requests each face the canvas draws with and repaints when it arrives; one-shot renders wait for their faces |
| Missing font | Fallback stack + soft issue `text/font-missing` |
| Paints (built) | `render/src/paint.ts`: CSS-angle linear gradients (`linearGradientLine`, shared with SVG export), elliptical radial gradients (unit circle in a scaled space), image patterns placed like `fit`; text runs shift the paint so a gradient spans the whole text box. Rich-text pieces share a baseline |
| Editing | DOM `contenteditable` mirror on the overlay layer; committed as one transaction on blur/Enter |

## Headless Parity

The same `draw/` code runs in all contexts. Golden-image tests render fixtures in Node and compare with the app's renders captured by Playwright (tolerance 0.1%) to catch divergence (fonts, GPU vs CPU AA).

---

## Rules

| # | Rule |
|---|---|
| 1 | `draw/*` functions are pure: `(canvas, node, resolved, ctx) → void`. No document access beyond `ctx` |
| 2 | Resolved values come from the core (variables already resolved) — render never resolves variables |
| 3 | Free every CanvasKit object (`.delete()`); `using`/helper `withPaint()` enforced by lint rule |
| 4 | No per-frame allocations in hot paths; reuse paints and paths |
