## Sets

Every icon is **one path** on a square grid, inserted as an editable `path` node (stroked for outline sets, filled for solid sets and logos).

| Set id (agent prefix) | Source · licence | Grid · mode | Count |
|---|---|---|---|
| `lucide` (no prefix) | lucide · ISC | 24 · stroke 2 | ~2 100 |
| `tabler`, `tabler-filled` | Tabler · MIT | 24 · stroke 2 / fill | ~5 000 / ~1 000 |
| `ph`, `ph-thin`, `ph-light`, `ph-bold`, `ph-fill` | Phosphor · MIT | 256 · fill | ~1 500 each (duotone left out: it needs two opacities) |
| `hero`, `hero-solid`, `hero-mini`, `hero-micro` | Heroicons · MIT | 24 / 20 / 16 · stroke 1.5 / fill | ~320 each |
| `logos` | Simple Icons · CC0 | 24 · fill, brand colour + title | ~3 500 |
| `my` | Uploaded by the person | node tree at natural size | — |

Brand logos remain trademarks of their owners; the panel says so and agents use them for references to that brand (social links, sign-in, "trusted by"), not as the product's own mark.

## Data

| Rule | Detail |
|---|---|
| Generation | `node scripts/gen-icon-sets.mjs` reads the source packages (root devDependencies) → `packages/icons/data/<set>.json` + `index.json`. Never edit the JSON by hand |
| Entry | `"d"` · `["d", "e"]` even-odd fill · logos `["d", "#hex", "Title"]` |
| Loading | Each set is its own lazily imported chunk (`loadIconSet`); `index.json` (meta + counts) is the only eager part. The renderer loads a set when its collection opens; "All icons" search loads all (~10 MB) once |
| Refs | `parseIconRef("tabler:home")`, aliases (`phosphor:`, `heroicons:`, `logo:`, `brand:`, `si:`, `custom:`); logo slugs drop separators (`logos:google-chrome` → `googlechrome`) |
| Search | `searchIcons(query, { sets?, limit? })` ranks across sets (exact → prefix → substring → all words → one word → typo distance); logos also match their title |
| Nodes | `iconNode(icon, { size, color, strokeWidth, name })` — stroke width scales with size/grid; logos default to their brand colour. Shared by the panel and `icon()` so both insert the same vector |

## My icons

| Rule | Detail |
|---|---|
| Store | `ARCHA_HOME/icons/custom.json` (`format: 'archa-icons'`), per machine, every document. Broken file → moved aside, never overwritten |
| Upload | SVG → `svgToNodes` (editable vectors; complex SVG falls back to an image), PNG/JPG/WebP → image node. A `preview` data URL is kept for the grid. Max 4 MB per icon, 200 per upload; taken names get `-2`, `-3` |
| RPC | `icons.custom.list` · `icons.custom.add { icons[] }` · `icons.custom.remove { name }` (zod-validated in the core host) |
| Insert | `customIconNode`: the tree scaled so its longest side = size (boxes, strokes, radii, gaps, padding, font sizes); a colour recolours every paint |

## Assets panel

Tool rail **Assets** button (grid icon) or **Shift+I**; the Shapes family's "Icons and logos…" opens it too. Floating card beside the rail (600 px).

| Area | Behaviour |
|---|---|
| Collections | All icons · Lucide · Tabler · Phosphor · Heroicons · Logos · My icons, with counts; families with styles show style chips (Outline/Filled, Regular…Fill, Outline/Solid/Mini/Micro) |
| Grid | 240 tiles, "Show more"; logos and my icons show a name. Tooltip = ref agents can use |
| Insert | Click → middle of the view (inside the frame there); drag → dropped at the pointer (`application/x-archa-icon`) |
| Footer | Size 16–64 · colour **Auto** (dark ink; light when placed straight on the dark page) or a picked colour · "Brand colours for logos" · set licence |
| Empty result | Offers to search every set for the same words |

Choices (collection, style, query, size, colour) persist while the window is open.

## Agents

`icon(ref, parent, { size, color, strokeWidth, … })` and `icons(query, { set, limit })` → [MCP/02](../MCP/02-execute-api.md). The core host loads every set before running a snippet that calls them. The `icons` design guide tells agents to keep one set per design and to use `logos:` instead of drawing logos.
