## Asset Store (content-addressed)

| Aspect | Rule |
|---|---|
| Key | sha256 of the original bytes |
| Path | `<store>/<first 2 hex>/<sha256>.<ext>` |
| Stores | Project: `.archadev/assets/` (committed). Standalone: `~/.archadev/cache/assets/` + embedded in the `.archa` |
| Dedup | Importing the same image twice stores it once |
| Derived | Decoded mip levels (`cache/mips/<sha>/<level>.webp`), never committed |
| Fonts | `~/.archadev/cache/fonts/` — embedded in `.archa` only if the font licence flag allows |

## Cache Index — `cache/index.sqlite`

```sql
CREATE TABLE entries (
  layer TEXT NOT NULL,          -- 'thumbs' | 'text' | 'mips' | 'agent' | 'export'
  key   TEXT NOT NULL,
  path  TEXT NOT NULL,
  bytes INTEGER NOT NULL,
  last_used INTEGER NOT NULL,   -- unix ms
  PRIMARY KEY (layer, key)
);
CREATE INDEX entries_lru ON entries(layer, last_used);
```

Eviction reads this index — it never walks the directory. Missing index → rebuilt by a background scan.

## Budgets (defaults, all configurable)

| Layer | Default cap | Policy |
|---|---|---|
| Thumbnails | 200 MB / project | LRU |
| Text shaping | 128 MB global | LRU |
| Mip levels | 1 GB global | LRU |
| Export cache | 500 MB global | LRU, 7-day TTL |
| Agent cache | 100 MB / project | LRU |
| Unreferenced assets (global store) | — | Delete after 30 days unreferenced |

Eviction runs at idle and when a write would exceed a cap.

## Performance Targets (CI benchmarks)

| Scenario | Target |
|---|---|
| Open 20k-node `.archa`, cold | < 1.5 s to first paint |
| Same file, warm cache | < 400 ms |
| Pan/zoom, 20k nodes | 60 fps p95, no frame > 32 ms |
| Single property edit → repaint | < 16 ms |
| Theme switch, 5k themed nodes | < 100 ms |
| Agent `execute` creating 200 nodes + screenshot (no model time) | < 500 ms |

Fixtures generated by `packages/core/bench/fixtures.ts` (deterministic seed). A regression > 10% fails CI.
