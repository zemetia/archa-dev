## What Shows When

| Selection | Header | Sections (top → bottom) |
|---|---|---|
| Nothing | "Design" | **Document** (rename → `doc.rename`, file path or "Not saved yet") · **Shortcuts** cheatsheet |
| Several layers | "N layers" | Alignment (with distribute, 3+) · Arrange (wrap in auto-layout frame Shift+A, group into frame Ctrl+Alt+G — same parent only) |
| One layer | Editable name + type icon (diamond = component) | Component row · Context · Alignment · Position · Auto layout (frames) · Dimensions · Appearance · Text (text) · Type extras · Fill · Stroke · Effects · Code · Export |

`NodeSections` is keyed by node id, so switching selection resets local field state.

## Section Rules

| Section | Behaviour |
|---|---|
| Component row | Plain frame → **Create component**. Main → instance count, **Push to instances**. Instance → **Sync** (`syncInstanceOps`), go to main, detach → [DESIGN_SYSTEM/02](../DESIGN_SYSTEM/02-components-libraries.md) |
| Context | Free-text note for agents in `meta.context`; shown in `get_state`, `inspect` and outline (`core/outline.ts`) |
| Alignment | 6 edges. A lone top-level layer has nothing to align to → toast says why. A child of auto layout changes the **parent's** `align` / `justify`, not its x/y (`inAutoLayout`) |
| Position | X / Y in parent space; "ignore auto layout" (absolute child) |
| Auto layout | Add (Shift+A) / remove; direction; 9-dot placement grid (distributed main axis lights the whole cross line); gap; space between / around; padding per axis or per side → [DOCUMENT_MODEL/03](../DOCUMENT_MODEL/03-layout.md) |
| Dimensions | W / H with **Fill** / **Hug** checkboxes; typing a size makes that axis fixed again |
| Appearance | Opacity %, corner radius, clip content (frames) |
| Text | Font, weight, size, line height (× size), letter spacing, alignment |
| Fill / Stroke | List sections: + adds, row show/hide and remove; hex + alpha %; stroke width + position (inside / center / outside; paths always centre) |
| Effects | Drop shadow, inner shadow, layer blur, background blur (`formatVersion` 3) |
| Type extras | Embed → Web page URL (adds `https://`); Image → fit (crop / fit / stretch); Path → line cap, join, fill rule |
| Code | HTML + Tailwind or HTML + CSS via `export.code`; copy to clipboard; the choice persists across selections |
| Export | PNG / JPG / SVG / PDF, scale 1–4×; `export.save` (raster rendered by the renderer, PDF printed by main `pdf.ts`) → [RENDERING/03](../RENDERING/03-export.md) |

## Rules

| # | Rule |
|---|---|
| 1 | Every edit is **one** `doc.apply` transaction with a human label (`'Opacity'`, `'Align children'`) — that label is the undo entry and the activity line |
| 2 | Arrange maths lives in `@archa/core` `arrange.ts`; the panel only builds ops from it. Agents get the same commands through `execute` (`align`, `distribute`, `wrap`) → [MCP/02](../MCP/02-execute-api.md) |
| 3 | When a command changes nothing, say why (toast) instead of failing silently |
| 4 | Text inputs stop key propagation so canvas shortcuts do not fire while typing; Enter commits, Escape restores |
| 5 | Tokens only, no raw colours → [02](./02-components-tokens.md) |

**Planned:** variable pickers on every value, theme switcher, Inspect tab (computed values + variable behind each) → [01 → Panels](./01-shell-tools-panels.md).
