## Projects

Every folder opened in ArchaDev is a **project** (Explorer "Open this folder with Archa", `--project <dir>`, File → Open folder… Ctrl+Shift+O). Owner's rule (2026-11-27): the folder gets a `.design/` folder and that is where its designs live.

| Item | Rule |
|---|---|
| Folder | `<project>/.design/` created on open (`workspace.restore`) |
| Designs | Any number of `<project>/.design/<name>.archa`, each with its `<name>-data/` ([01](./01-archa.md)) |
| New design | Untitled in memory; first save (manual or auto) writes `.design/<name>.archa` without a dialog, numbered when taken (`Untitled 2.archa`) |
| `--project <dir>\.design` | Means the project `<dir>` |
| First open, nothing remembered | Opens the newest `.archa` in `.design/`, else one untitled design |
| Title bar | Project chip: folder name → list of `.design/*.archa` (open ones dotted), New design, Show in Explorer |

## Window Contexts

One window = one context: a project folder, or **public** (no folder). The core host holds every window's documents; `DocSummary.project` says which context a document belongs to and each renderer shows only its own (`sameProject`). `doc.new`/`doc.open` take the window's `project`; agents and the CLI omit it and get the context of the document used last. Opening a file that is open in another window moves it to the asking window. Closing a context's last document leaves a new untitled one.

## Restore (VS Code-like)

`ARCHA_HOME/runtime/open-files.json` — per context key (`''` = public, else the lower-cased folder):

```json
{ "version": 1, "contexts": { "": { "project": null, "docs": [{ "path": "D:/x/a.archa", "name": "a" }, { "backup": "<docId>", "name": "Untitled" }], "active": 0 } } }
```

| Entry | Reopens as |
|---|---|
| `path` | The file |
| `backup` (+ optional `path`) | `ARCHA_HOME/runtime/backups/<docId>.archa`, dirty, same doc id (so its runtime data folder still resolves) |

Written 250 ms after any `workspace.changed`; a window's `workspace.restore` reopens its entries once per run. Backups nothing points at are deleted on write. Pristine untitled documents are never remembered.

## Auto-save

`ARCHA_HOME/settings.json` → `{ "autosave": { "enabled": true, "seconds": 45 } }` (5–3600), Settings → General.

| Trigger | Action on each dirty document |
|---|---|
| Every `seconds` | Has a file or a project → save; public untitled → backup |
| Agent finished (`agent.done`, `chat.run` not running) | Same, for that document |
| Quit (main waits ≤ 5 s for the core host) | Auto-save on → save as above; off → backup (dirty files keep their file untouched) |

Saves of one document are serialised (`saveDoc`); edits that land during a write keep it dirty.
